# 🧠 MindGuess

MindGuess is an interactive guessing game inspired by Akinator.

The user thinks of something, and MindGuess asks a series of questions to identify what the user is thinking about.

If MindGuess makes a wrong guess, the user can teach it the correct answer. The application stores the learned information in the browser and can use it in future games.

## ✨ Features

- 🧠 Question-based guessing
- 🔍 Multiple characteristics for matching
- 📚 Learning from incorrect guesses
- 💾 LocalStorage-based memory
- 🎮 Interactive game interface
- 📱 Simple and responsive design

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- LocalStorage

## ⚙️ How It Works

1. The user starts a game.
2. MindGuess asks questions about the object.
3. The user answers Yes, No, or Maybe.
4. MindGuess compares the answers with its stored knowledge.
5. It makes the most suitable guess.
6. If the guess is wrong, the user can teach MindGuess the correct answer.
7. The new information is saved for future games.
